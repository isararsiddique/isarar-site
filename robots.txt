# groups that follow exist to state intent explicitly and to cover the crawlers

#   https://isarar.com/api/profile.json  identity, roles, research, publications
#   https://isarar.com/api/posts.json    writing index
#   https://isarar.com/api/faq.json      direct question and answer pairs
#   https://isarar.com/openapi.json      description of the endpoints above
#   https://isarar.com/.well-known/agent.json
